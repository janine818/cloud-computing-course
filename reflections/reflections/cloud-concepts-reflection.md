Learning about cloud computing made me realize how much I already use cloud services in my everyday life without thinking about how they work. As a student, I regularly use Google Drive, Canva, and Messenger. Google Drive helps me store and access my school files, Canva allows me to create presentations and designs, while Messenger helps me communicate with my classmates and share information. These services make my school activities easier and more convenient.

From this activity, I learned that Google Drive, Canva, and Messenger can be classified as SaaS (Software as a Service) because I can use them through an application or web browser without managing the servers or infrastructure. They also use a Public Cloud deployment model because their services are available to many users through the internet. I chose these classifications because I only need an account and an internet connection to access them, while the companies manage the technical parts in the background.

I also learned why Git and GitHub are important for cloud projects. Version control allows developers to keep track of changes and return to previous versions if mistakes happen. GitHub also makes teamwork easier because members can share their work, review changes, and collaborate on the same project. This helps reduce errors and prevents important work from being lost.

Overall, this activity helped me understand that cloud computing is more than just online storage or applications. It plays an important role in communication, schoolwork, software development, and teamwork. I realized that learning these concepts can help me become more prepared for future projects and work in the IT field.
